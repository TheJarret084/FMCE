# HOLA

imagino que no sabes que es esto, entonces te explico rapido

este es un engine de FNF, hecho para crear/modificar Proyectos de Fubky maker: Mobile

hasta ahora todos los editores andan 99% funcionales, solo faltan terminarlos de pulir

y ahora solo falta que termine demas cosas como optimizarlo, aunque problemas de rendimiento no vas a tener


# recomendaciones

- tener un mobile de 4GB de ram, en caso de pc igual
- tener 1GB de espacio libre, para guardar tus proyectos o canciones propias
- tener conocimiento minimo de lo que haces en caso de hacerlo por tu cuenta un nivel
